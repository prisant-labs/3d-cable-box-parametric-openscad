# Multi-port USB-C charger

A GaN multi-port charger and 4 to 6 USB-C cables.

Printed box envelope: `120.0 x 75.0 x 45.0 mm`

## Parameters

| Parameter | Value |
|---|---|
| `All_Opening_Height` | `26` |
| `All_Opening_Width` | `12` |
| `Box_Depth` | `75` |
| `Box_Height` | `45` |
| `Box_Width` | `120` |
| `Post_Diameter` | `12` |

Everything not listed uses the model default.

## Rebuild

```bash
python scripts/build_library.py --only usb-charger
```
