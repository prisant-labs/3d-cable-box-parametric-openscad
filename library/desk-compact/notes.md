# Compact desk tidy

A short power strip plus 3 or 4 cables. Minimal desk footprint.

Printed box envelope: `140.0 x 80.0 x 55.0 mm`

## Parameters

| Parameter | Value |
|---|---|
| `All_Opening_Height` | `32` |
| `All_Opening_Width` | `14` |
| `Box_Depth` | `80` |
| `Box_Height` | `55` |
| `Box_Width` | `140` |

Everything not listed uses the model default.

## Rebuild

```bash
python scripts/build_library.py --only desk-compact
```
