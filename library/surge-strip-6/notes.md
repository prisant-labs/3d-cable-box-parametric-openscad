# Six-outlet surge protector

A standard 6-outlet strip up to ~250 x 60 mm, with its cord.

**Note:** Wider than many print beds. See the sliced preset below if that is a problem.

Printed box envelope: `265.0 x 100.0 x 62.0 mm`

## Parameters

| Parameter | Value |
|---|---|
| `All_Opening_Height` | `38` |
| `All_Opening_Width` | `20` |
| `Box_Depth` | `100` |
| `Box_Height` | `62` |
| `Box_Width` | `265` |
| `Stabilizers_Front_Back_Count` | `5` |

Everything not listed uses the model default.

## Rebuild

```bash
python scripts/build_library.py --only surge-strip-6
```
