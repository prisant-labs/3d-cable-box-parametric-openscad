# Router and modem shelf tidy

A small router or modem plus its PSU. Tall openings for stiff coax and ethernet.

**Note:** Powered equipment generates heat. PLA softens around 55 C; prefer PETG for anything left running.

Printed box envelope: `230.0 x 130.0 x 75.0 mm`

## Parameters

| Parameter | Value |
|---|---|
| `All_Opening_Height` | `45` |
| `All_Opening_Width` | `22` |
| `Box_Depth` | `130` |
| `Box_Height` | `75` |
| `Box_Width` | `230` |
| `Stabilizers_Front_Back_Count` | `4` |
| `Stabilizers_Left_Right_Count` | `2` |

Everything not listed uses the model default.

## Rebuild

```bash
python scripts/build_library.py --only router-shelf
```
