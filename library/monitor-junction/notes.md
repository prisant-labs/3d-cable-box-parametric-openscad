# Dual-monitor cable junction

Two monitor power bricks and their signal cables.

Printed box envelope: `210.0 x 95.0 x 62.0 mm`

## Parameters

| Parameter | Value |
|---|---|
| `All_Opening_Height` | `36` |
| `All_Opening_Width` | `18` |
| `Box_Depth` | `95` |
| `Box_Height` | `62` |
| `Box_Width` | `210` |
| `Stabilizers_Front_Back_Count` | `4` |

Everything not listed uses the model default.

## Rebuild

```bash
python scripts/build_library.py --only monitor-junction
```
