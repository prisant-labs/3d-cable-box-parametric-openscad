# Laptop brick and cables

One laptop charger up to ~150 x 75 x 40 mm, plus 3 cables.

Printed box envelope: `175.0 x 105.0 x 70.0 mm`

## Parameters

| Parameter | Value |
|---|---|
| `All_Opening_Height` | `38` |
| `All_Opening_Width` | `16` |
| `Box_Depth` | `105` |
| `Box_Height` | `70` |
| `Box_Width` | `175` |
| `Stabilizers_Front_Back_Count` | `4` |

Everything not listed uses the model default.

## Rebuild

```bash
python scripts/build_library.py --only laptop-brick
```
